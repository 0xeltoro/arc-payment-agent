Arc Payment Agent

agent pays, contract decides

The problem

  • Agents hold funds
  • Limits live in the agent's own code
  • A guard guarding itself

The approach

Policy lives below the agent, enforced onchain.

The agent's key calls exactly one function:
executePayment(to, amount)

On every call, the contract checks

  • Recipient allowlist
  • Per-tx cap
  • Daily cap
  • Pause

Only the owner can

setPolicy
setAgent
addRecipient
pause
withdraw

Architecture

   owner                                  agent
   |  setPolicy, addRecipient,            |  executePayment(to, amount)
   |  pause/unpause, withdraw             |  <- the only call the agent can make
   v                                      v
           PaymentVault (holds USDC)
